# Arrangement audition binding

The listening queue waveform editor has explicit Apply and audition mixed arrangement, Save arrangement and GET readback controls. Local audition uses only the existing service-owned ExoPlayer, `soundqmix` loader and source-built JNI renderer. Download each source first. No backend save or paid preparation is required to audition a plain draft.

Apply freezes the accepted occurrence document. Rate-one only, four half-open simultaneous occurrences maximum, bounded float-WAV size. Non-one rates refuse before replacing the owner. Neutral gain0 and pitch preserve are explicit because the canonical saved-plan API emits those defaults. Stem/gain/fade/tempo extensions from saved mixes are not flattened into this plain editor.

The service owns an accepted source occurrence snapshot and holds the original MediaItems while mixed. Controller queue and editor observation project that snapshot, never the mix MediaItem as track zero. Ordinary reorder/remove/queue-playlist controls are unavailable while mixed. Return to source queue restores exact occurrence IDs paused. Explicit context replacement remains a new source. Global ruler release seeks the same ExoPlayer paused; outside mixed mode it auditions one source occurrence in source time. Audio progress comes from actual Exo position, not a Compose clock.

Admission binds request, service incarnation, account epoch, queue incarnation and exact document revision. One bounded repository capture fences queued route cancellation and READY autoplay. Accepted installation ACK is not audible proof. Later draft edits leave the old installed snapshot unchanged until another explicit Apply. Stop, seek, queue changes, custom Undo, errors, route retirement and account/local-lock changes retire pending autoplay. Local unlock refreshes grants and stays paused. TimelinePanel also observes its native LifecycleOwner. Leaving RESUMED increments a pending-intent generation, so STOP followed by RESUME cannot revive an old Apply/Save/GET predicate while composition stays mounted. A new foreground interaction captures a fresh generation. This fence does not pause an already-authorized player or reset uncertain writes.

Save invokes the existing canonical POST/PUT plus exact GET. Each reservation has one entry and matching-token completion. The only supported scheduling path links cancellation even when a composition job never enters; that proven-unentered path restores prior state. Once a write body enters, cancellation or lifecycle loss never clears its conservative uncertain-write block. An uncertain write remains blocked across panel reentry. Recovery uses an explicit saved-mix UUID and GET, with exact occurrence/trim/placement comparison. It never repeats create automatically. Opening a saved mix in the existing Mixes route does not silently rewrite the waveform editor.

`android/scripts/test-arrangement-source.py` extracts the actual production service admission, player-command callback, READY callback and controller global-seek method. Hardware/Media3 objects are declared host facades. The real repository/account/strict mapping/NativeMixStream and JNI decode/render run in host tests. The compiled ArrangementJourneyTest mounts the normal app/editor and exercises downloaded Opus, duplicate source IDs, explicit Apply, global seek, POST/GET and source return. Device execution remains the runtime owner's separate gate.
